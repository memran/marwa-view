# Examples

The examples are organized by concern:

- `basic/`: generic rendering, extensions, namespaced views, and stack usage
- `theme/`: theme registry, theme bootstrap, and admin preview/apply/revert workflow

Recommended entry points:

- `index.php`
- `basic/index.php`
- `basic/render-demo.php`
- `basic/demo.php`
- `theme/index.php`
- `theme/theme.php`
- `theme/switch-theme.php`
