# Support

## Documentation First

Start with:

- [README.md](./README.md)
- [docs/README.md](./docs/README.md)
- [examples/README.md](./examples/README.md)

## Where to Ask

- use GitHub issues for reproducible bugs and concrete feature requests
- use pull requests for proposed code and documentation changes
- use repository documentation and examples for setup and usage questions first

## Before Opening an Issue

- confirm the problem against the latest repository state
- run `composer ci`
- check the examples under `examples/`
- include a minimal reproduction if possible

## Security Issues

Security issues should not be reported publicly. Follow [SECURITY.md](./SECURITY.md).
