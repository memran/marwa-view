# Code of Conduct

## Our Standard

This project expects respectful, professional, and constructive collaboration.

Examples of expected behavior:

- using welcoming and inclusive language
- giving technical feedback directly but respectfully
- assuming good intent while discussing tradeoffs
- focusing on code, behavior, documentation, and maintainability instead of personal attacks
- accepting responsibility for mistakes and correcting them quickly

Examples of unacceptable behavior:

- harassment, insults, or discriminatory language
- bad-faith arguments, trolling, or deliberate disruption
- publishing private information without permission
- repeated unconstructive hostility after moderation requests

## Scope

This code of conduct applies to:

- issues
- pull requests
- code review discussions
- repository discussions
- any public spaces representing this project

## Enforcement

Project maintainers may remove, edit, or reject contributions and comments that violate this code of conduct.

## Reporting

For conduct concerns, contact the maintainer through the security/support channels listed in [SUPPORT.md](./SUPPORT.md).
